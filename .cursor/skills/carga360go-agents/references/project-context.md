# Project Context — Carga360go.cl

## What is CARGA360GO?

CARGA360GO (also referred to as Carga 360 Go) is a web-based business application project hosted at carga360go.cl. Development focuses on advancing from drafts to concrete, visible progress on the page through coordinated AI-assisted workflows.

## Goals

- Move from draft mode to actual construction and visible features
- Unblock ("destrabar") development progress
- Respond efficiently to pending decisions (including those from "el dueño")
- Coordinate multi-agent setups: Cursor (code), Grok (reasoning and missions), Grok Bots (persistent routines and memory)

## Typical Working Modes

| Mode | Description | When to Use |
|------|-------------|-------------|
| Drafts only | Generate ideas, outlines, or non-published content | Explicitly requested (e.g., "only drafts") |
| Unblock & Decide | Identify blockers, present options, respond to decisions | Pending items exist |
| Build & Advance | Implement features, edit code, make progress visible | Default when not restricted |
| Coordinate | Set up or run multi-agent flows and routines | Ongoing project management |

## Key Phrases from Coordination

- "empiecen a construir en la página" — start building on the page
- "destrabar el desarrollo" — unblock development
- "misiones oficiales Grok Build" — official Grok Build missions
- References to bot, jefe, and Grok collaboration

## Decision Log Pattern

When responding to or recording decisions:

1. State the decision or pending item clearly
2. List options considered (if any)
3. Record the chosen path and rationale
4. Note next concrete action and responsible agent
5. Update shared memory or project notes

Persist important context across sessions using available memory mechanisms or bot routines.
