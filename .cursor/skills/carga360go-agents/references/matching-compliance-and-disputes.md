# Matching, verificación y resolución

Ranking de coincidencias: capacidad, tipo de vehículo, región, ubicación estimada, ventana de retiro, documentos, restricciones de carga, disponibilidad y calidad de servicio. Los filtros duros (empresa autorizada, documentos vigentes, conductor apto, GPS requerido) se aplican ANTES de puntuar o enviar alertas.

Guardar razones explicables de postulación/elegibilidad. No asignar automáticamente una carga con exigencias especiales sin confirmar certificados y autorizaciones. Controlar duplicados, cuentas fraudulentas y conflicto de interés.

Escalamiento de reclamos: ticket -> severidad -> pruebas (GPS/QR/documentos/mensajes) -> revisión imparcial -> resolución autorizada -> comunicación auditada. Nunca declarar una entrega cumplida con una única señal de GPS.
