# Plan de implementación incremental

Fase 0: inventario de repositorio, ramas, dependencias, conexiones, respaldo, mapa de permisos y riesgos; confirmar estado real.
Fase 1: cerrar bloqueos de acceso SSH, revisar PR #1 y #2 sin asumir aprobación, verificar verificación documental en matching, panel administrador y 403.
Fase 2: corregir rutas/cotizador con datos tarifarios versionados y pruebas de regresión de Antofagasta–Santiago, peajes por ejes y diésel.
Fase 3: GPS/QR, torre de control, evidencia de entrega y eventos de flota.
Fase 4: agente central, FAQs, WhatsApp/correo/voz, CRM y solicitudes de reuniones con consentimientos.
Fase 5: dashboard de KPIs, instrumentación, auditoría, rendimiento, accesibilidad y plan de contingencia.

Cada fase produce: PR, resumen del diff, evidencia de pruebas, captura de staging, lista de incidencias y estado 'pendiente de autorización de producción'. Datos del plan son contexto histórico, nunca prueba del estado actual del repositorio.
