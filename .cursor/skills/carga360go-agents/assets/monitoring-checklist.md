# Checklist — Sesión de monitoreo / extracción (Carga360go)

- [ ] Credenciales disponibles (env / secreto)
- [ ] Navegador headless iniciado (Playwright/Puppeteer)
- [ ] Login exitoso y sesión activa (cookies guardadas)
- [ ] Navegación a vistas clave:
  - [ ] Bolsa de cargas
  - [ ] Camiones
  - [ ] Calculadora (si aplica)
  - [ ] Panel / alertas
- [ ] Datos extraídos (tablas, estados, tarifas)
- [ ] Datos normalizados
- [ ] Reporte generado (Markdown / CSV / Excel)
- [ ] Comparación con estado anterior (si existe)
- [ ] Entrega / handoff a bot o usuario
- [ ] Sesión cerrada o mantenida según necesidad
